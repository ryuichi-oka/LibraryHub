# LibraryHub 実装タスク（MVP）

## 0. 進め方ルール
- ステータスは `TODO / DOING / DONE / BLOCKED` を使用する
- 各タスクは対応する要件ID（FR/NFR/CA）を明記する
- 実装タスクは担当レイヤーを明示する（`[API] / [WEB] / [BATCH] / [DOCS]`）
- 実装完了時は確認結果を記録し、必要に応じて `requirements.md` と `design.md` を更新する
